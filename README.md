# LandWolf historical archive — October 11, 2026

This branch preserves every branch tip recorded before repository cleanup, including unmerged private-seller work, marketing assets, and the former default application. It is not a release or deployment branch.

See `BRANCHES.json` for exact branch names and commits. Each distinct tip is a parent of this archival commit, keeping its complete history and files reachable. Browse any recorded commit in GitHub or restore it with `git fetch origin archive/pre-cleanup-2026-10-11` followed by `git switch -c <restored-name> <recorded-sha>`.

Current supported source belongs on `main`; isolated verification belongs on `staging`. Accounts, billing, databases, domains, and the running image are outside this Git archive and are not modified by it.
